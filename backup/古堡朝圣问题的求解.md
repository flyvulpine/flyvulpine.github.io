# 问题描述
从前有一名小贩信徒，每日从家（点P）出发，需先至圆形古堡上某点A朝拜某位于圆心O的神像，再前往集市（点Q），问如何选择P点使路径AP+PB最短？
### 几何抽象
**已知定圆O及园外两定点P，Q，在圆周上求一点A，使得PA+AQ取得最小A值.**

<img width="600" height="500" alt="Image" src="https://github.com/user-attachments/assets/a1749bc1-ed2f-4886-b193-2b72efdbc877" />

### 常数设定
设圆心(a,b)，半径r，P坐标(x<sub>1</sub>,y<sub>1</sub>)，Q坐标(x<sub>2</sub>,y<sub>2</sub>)，动点A坐标(x,y).
**这里以 a = 2, b = -1, r = 3， x<sub>1</sub> = 5, y<sub>1</sub> = 1, x<sub>2</sub> = -2, y<sub>2</sub> = 4为例**.

## 第一种暴力解法
我们有一种很直接的想法，就是穷举圆上所有的点A，然后计算所有的PA+AQ，通过比较得到最小值.
这里的计算显然是复杂的，我们可以交给计算机.

### 暴力解法code示例
```cpp
#include <iostream>
#include <cmath>
#include <iomanip>
using namespace std;

int main() {
    // 常数
    double a = 2, b = -1, r = 3;
    double x1 = 5, y1 = 1, x2 = -2, y2 = 4;

    double best_theta = 0;
    double min_dist = 1e9;

    // 暴力扫描：角度步长 0.0001 弧度
    for (double theta = 0; theta < 2 * M_PI; theta += 0.0001) {
        double x = a + r * cos(theta);
        double y = b + r * sin(theta);

        double d1 = sqrt(pow(x - x1, 2) + pow(y - y1, 2));
        double d2 = sqrt(pow(x - x2, 2) + pow(y - y2, 2));
        double total = d1 + d2;

        if (total < min_dist) {
            min_dist = total;
            best_theta = theta;
        }
    }

    double x_ans = a + r * cos(best_theta);
    double y_ans = b + r * sin(best_theta);

    cout << fixed << setprecision(6);
    cout << "最短路径点: (" << x_ans << ", " << y_ans << ")" << endl;
    cout << "最短总距离: " << min_dist << endl;

    return 0;
}
```

以上使用了圆的参数方程，遍历θ得到结果.
利用c++我们很快就可以跑出结果（精度可以修改θ的步长).

```
最短路径点：（3.172664，1.761315）
最短路径：7.615911
```

## 第二种解析方法
我们想要用解析法尝试找到满足题目条件的A，应该满足怎样的约束条件？
或者能否使用尺规作图找出这个A点？

### 由直线到圆
这个问题如果在直线上，那么就是将军饮马问题，就是做对称，定点P的对称点P’，动点A‘，与另一个定点Q三点共线时，距离取得最小值.

<img width="600" height="500" alt="Image" src="https://github.com/user-attachments/assets/feb102ba-2af0-4b76-9503-389c96294dda" />

### 解析法求A须满足的条件
那么在一个圆中，我们怎样把这个问题转化再到直线上呢？
很容易想到作**圆的切线**，在圆的切线上找一点B不同于A，延长PA交圆于C，如下图.

<img width="571" height="458" alt="Image" src="https://github.com/user-attachments/assets/c2046eee-9266-4a5e-9475-92ed08daa29d" />

> [!NOTE]
> C点怎么取？这里PA与圆相离时不考虑，与圆相切时取切点，与圆相交于两个交点时，取第一个交点（显然，第二个交点的距离比第一个交点来得远).

在这里我们将P关于切线作对称，利用将军饮马的思路求出，再切线上哪个点D，可以使得PD+DQ的距离最小.

<img width="566" height="563" alt="Image" src="https://github.com/user-attachments/assets/cffc8a2f-1382-4eb3-a30f-a841b0432038" />

由于我们有PC+CQ＞PB+BQ＞PD+DQ
那么这里我们只需要找到一点A，让D与A重合即有:
PC+CQ＞PB+BQ＞PA+AQ

<img width="560" height="600" alt="Image" src="https://github.com/user-attachments/assets/4fedd92e-a3eb-4519-97f2-b0b919f25cb1" />

> [!TIP]
> 这个点A满足反射角等于入射角（在后面可以推出椭圆的光学性质）

### 点A代数约束条件的求解
上述的点A满足反射角等于入射角.
这里可以作直线OA，取A上方直线的一个点E，以上条件可以描述为∠PAE=∠EAQ
我们在这里利用向量的方法表示两个夹角.
为了方便坐标表示，不妨使得AE=OA，这样使得 $\overrightarrow{OA}=\overrightarrow{AE}$.

<img width="581" height="550" alt="Image" src="https://github.com/user-attachments/assets/b16a3738-8812-471d-bab4-166473648428" />

cos∠PAE= $\frac{\overrightarrow{AP}·\overrightarrow{AE}}{|AP||AE|}$
cos∠EAQ= $\frac{\overrightarrow{AQ}·\overrightarrow{AE}}{|AQ||AE|}$
由于∠PAE=∠EAQ，又有 $\overrightarrow{OA}=\overrightarrow{AE}$，所以有下式
 $\frac{\overrightarrow{AP}·\overrightarrow{OA}}{|AP|}=\frac{\overrightarrow{AQ}·\overrightarrow{OA}}{|AQ|}$

这里可以用向量数量积的坐标运算展开，得到第一个约束
 $\frac{(x_1-x)(x-a)+(y_1-y)(y-b)}{\sqrt{(x-x_1)^2+(y-y_1)^2}}=\frac{(x_2-x)(x-a)+(y_2-y)(y-b)}{\sqrt{(x-x_2)^2+(y-y_2)^2}}$
又有A在圆上，所以有
 $(x-a)^2+(y-b)^2=r^2$

由上述得到的两个约束，x，y满足一个四次有理方程，可以通过差分或牛顿迭代法等求得数值解.

### 求A最终的数值解
解上述的四次方程，可以得到四个解（含复数解）t<sub>1</sub>,t<sub>2</sub>,t<sub>3</sub>,t<sub>4</sub>
这里由于平方操作会产生增根，所以需要带回去检验消除增根.
检验之后剩下的根也不一定是唯一的，因为直线是有可能与圆产生两个交点的，因此需要进一步检验.

由上述可知，想要算出A的数值解计算量庞大（这也映证了使用尺规作图寻找点A的难度之大，当然这已经有数学家给出了完整的证明）

### 将表达式转化为非齐次线性一元方程

- 由于使用牛顿迭代法需要为一元方程，我们采用圆的参数方程进行一元化
> [!NOTE]
> 如何将上式转化为非齐次线性一元方程？先对坐标进行平移简化，令u=x-a，v=y-b，则圆变为u<sup>2</sup>+v<sup>2</sup>=r<sup>2</sup>,设圆上A(x,y)，定点变为P‘=(u<sub>1</sub>,v<sub>1</sub>)=(x<sub>1</sub>-a,y<sub>1</sub>-b)，Q'=(u<sub>2</sub>,v<sub>2</sub>)=(x<sub>2</sub>-a,y<sub>2</sub>-b)。此时上述的第一个约束条件化为: $\frac{P'·A - r^2}{|P'-A|}=\frac{Q'·A - r^2}{|Q'-A|}$，其中点积 $P'·A=u_1u+v_1v$, $|P'-A|=\sqrt{(u-u_1)^2+(v-v_1)^2}$，接下来参数化，令A=(u,v)=r(cosθ,sinθ)，则: $P'·A = r(u_1cosθ+v_1sinθ)，|P'-A|^2 = |P'|^2+r^2-2P'·A$，记 $\alpha = u_1,\ \beta=v_1,\quad \gamma=u_2,\ \delta=v_2,\quad \rho=r.$此时第一个约束可以化为： $\frac{\rho(\alpha\cos\theta+\beta\sin\theta)-\rho^2}{\sqrt{\alpha^2+\beta^2+\rho^2-2\rho(\alpha\cos\theta+\beta\sin\theta)}}=\frac{\rho(\gamma\cos\theta+\delta\sin\theta)-\rho^2}{\sqrt{\gamma^2+\delta^2+\rho^2-2\rho(\gamma\cos\theta+\delta\sin\theta)}}.$接下来可以转化为四次方程，先两边平方（这里会产生增根，可能是外角平分线): $\left(\alpha\cos\theta+\beta\sin\theta-\rho\right)^2\left(\gamma^2+\delta^2+\rho^2-2\rho(\gamma\cos\theta+\delta\sin\theta)\right)=\left(\gamma\cos\theta+\delta\sin\theta-\rho\right)^2\left(\alpha^2+\beta^2+\rho^2-2\rho(\alpha\cos\theta+\beta\sin\theta)\right).$，利用万能公式化简，令 $t=\tan\frac{\theta}{2}$，则 $\cos\theta=\frac{1-t^2}{1+t^2},\quad \sin\theta=\frac{2t}{1+t^2}.$，代入之后，每一项都是关于 t 的有理函数。乘以公共分母 $(1+t^2)^2$（非零）后，得到关于 t 的多项式方程。因为 $\cos\theta,\sin\theta$ 中分母为 $1+t^2$，而平方后分母最高为 $(1+t^2)^2$，分子最高次数为 2，故整理后最高次数为 4。即总能写成： $A_4 t^4 + A_3 t^3 + A_2 t^2 + A_1 t + A_0 =0.$

- 按照上述的方式可以将第一个约束表达为线性一元方程，进而使用牛顿迭代法，当然这里的系数展开略显冗杂，这里不多赘述.

### 解析法+牛顿迭代法求A数值解code示例

```cpp
#include <iostream>
#include <cmath>
#include <vector>
#include <iomanip>   // 用于控制输出精度
using namespace std;

double al, be, ga, de, rho;

double F(double t) {
    double t2 = t*t, ot = 1+t2;
    double P1 = al*(1-t2) + 2*be*t - rho*ot;
    double P2 = ga*(1-t2) + 2*de*t - rho*ot;
    double S1 = al*al + be*be + rho*rho;
    double S2 = ga*ga + de*de + rho*rho;
    double Q1 = S2*ot - 2*rho*(ga*(1-t2) + 2*de*t);
    double Q2 = S1*ot - 2*rho*(al*(1-t2) + 2*be*t);
    return P1*P1*Q1 - P2*P2*Q2;
}

double dF(double t) { double h=1e-7; return (F(t+h)-F(t-h))/(2*h); }

double newton(double t0) {
    double t=t0;
    for(int i=0;i<200;i++){  // 增加迭代次数以防不收敛
        double f=F(t), df=dF(t);
        if(fabs(df)<1e-15) break;
        double nt = t - f/df;
        if(fabs(nt-t)<1e-12) return nt;
        t=nt;
    }
    return t;
}

bool valid(double t) {
    double th=2*atan(t), u=rho*cos(th), v=rho*sin(th);
    double dpA = al*u+be*v, dpB = ga*u+de*v;
    double dA = sqrt((u-al)*(u-al)+(v-be)*(v-be));
    double dB = sqrt((u-ga)*(u-ga)+(v-de)*(v-de));
    if(dA<1e-12 || dB<1e-12) return false;
    return fabs((dpA-rho*rho)/dA - (dpB-rho*rho)/dB) < 1e-9;
}

int main(){
    double a=2,b=-1,r=3, x1=5,y1=1, x2=-2,y2=4;
    al=x1-a; be=y1-b; ga=x2-a; de=y2-b; rho=r;

    vector<double> roots;
    for(double t0=-100; t0<100; t0+=0.01){// 扫描步长 
        if(F(t0)*F(t0+0.01)<0){
            double root = newton((t0+t0+0.01)/2);
            bool dup=false;
            for(size_t i=0;i<roots.size();i++) if(fabs(roots[i]-root)<1e-8) dup=true;
            if(!dup) roots.push_back(root);
        }
    }

    double extra[]={-10,-5,-1,0,1,5,10};
    for(int i=0;i<7;i++){
        double root=newton(extra[i]);
        if(fabs(root)<1000){
            bool dup=false;
            for(size_t j=0;j<roots.size();j++) if(fabs(roots[j]-root)<1e-8) dup=true;
            if(!dup) roots.push_back(root);
        }
    }

    double bestX=0,bestY=0,bestDist=1e18;
    int cnt=0;
    for(size_t i=0;i<roots.size();i++){
        double t=roots[i];
        if(!valid(t)) continue;
        double th=2*atan(t), u=rho*cos(th), v=rho*sin(th);
        double x=a+u, y=b+v;
        if(fabs((x-a)*(x-a)+(y-b)*(y-b)-r*r)>1e-7) continue;
        double d1=sqrt((x-x1)*(x-x1)+(y-y1)*(y-y1));
        double d2=sqrt((x-x2)*(x-x2)+(y-y2)*(y-y2));
        double dist=d1+d2;
        if(dist<bestDist){ bestDist=dist; bestX=x; bestY=y; }
        cnt++;
    }

    if(cnt==0){
        cout<<"无解\n";
    } else {
        // 输出设置
        cout<<fixed<<setprecision(12);
        cout<<"最短路径点: ("<<bestX<<", "<<bestY<<")  距离="<<bestDist<<"\n";
    }
    return 0;
}
```

> [!IMPORTANT]
> 简单解释一下牛顿迭代法：选择一个x作为初始迭代点，作切线与x轴交于一点，作为下一次的迭代点，迭代公式： $x_{n+1}=x_n-\frac{f(n)}{f'(n)}$，其中f'(n)≠0.

> [!CAUTION]
> 特别注意：牛顿迭代法仅适用非齐次线性一元方程的求根.

## 古堡朝圣问题与椭圆光学性质的联系
由上述的古堡朝圣问题很快可以得到椭圆的光学性质：从一个焦点发射的光线经椭圆反射后一定经过另一个焦点.
这是因为A距离最短并且满足反射角等于入射角.

> [!NOTE]
> 这里由于椭圆离心率不确定，所以切点不一定唯一，即点A不一定唯一，之后再尝试证明切点是唯一的.
